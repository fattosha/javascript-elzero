Tasks

Task 01 — Nested Functions

Created a "getDetails" function containing four nested functions:

- "namePattern()" — formats the name as "Osama M."
- "ageWithMessage()" — extracts the age from a message.
- "countryTwoLetters()" — gets the first two letters of the country in uppercase.
- "fullDetails()" — combines all results into one final message.

Example Output:

Hello Osama M., Your Age Is 38, You Live In EG
Hello Ahmed A., Your Age Is 32, You Live In SY

Task 02 — Arrow Functions

Converted regular functions to Arrow Function syntax.

Covered:

- Function expression
- Arrow Function syntax
- Parameters
- Return values

Task 03 — Currying

Converted a nested function into Arrow Function syntax using the Currying Function Technique.

checker("Osama")("Available")(4000);

Each function receives one parameter and returns another function until the final result is produced.

Task 04 — Special Mix

Created a "specialMix" function using Rest Parameters to accept an unknown number of arguments.

The function handles:

- Numbers
- Strings containing numbers
- Strings without numbers
- Extracting numbers from strings
- Calculating the final sum
- Detecting when all arguments are strings

Examples:

60
30
50
All Is Strings
