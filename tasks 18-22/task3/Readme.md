About The Task

A JavaScript challenge focused on working with a numeric value stored as a String and using different operators and techniques to produce the same result:

«20»

---

Solutions

let num = "10";

// Solution One
console.log(num * (true + true)); // 20

// Solution Two
console.log(+num + +num); // 20

// Solution Three
console.log((true + true + true + true) * num / (true + true)); // 20

// Solution Four
console.log(+num * +num / +num + +num); // 20
