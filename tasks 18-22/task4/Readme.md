About The Task

A JavaScript task focused on using Increment "++" and Decrement "--" operators to modify the value of a variable and reach the expected results.

---

Solution

let points = 10;

points++;
++points;
points++;

console.log(points); // 13

points--;
--points;
points--;
--points;
points--;

console.log(points); // 8
