About The Task

A JavaScript challenge where the goal is to use different arithmetic operators and Boolean values to make every solution return the same result:

«6»

---

Solutions

let num = 3;

// Solution One
console.log(num * (true + true)); // 6

// Solution Two
console.log(num + num); // 6

// Solution Three
console.log(num ** (true + true) - num); // 6

// Solution Four
console.log(num * (true + true + true) - num); // 6

// Solution Five
console.log(num / (true + true) + num); // 6

// Solution Six
console.log(num * num / num + num); // 6
