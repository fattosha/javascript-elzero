Loop through the "friends" array and remove every name that starts with the letter "A", then print the remaining friends with their indexes.

Concepts

- Arrays
- "for" loop
- "splice()"
- "toLowerCase()"
- Array indexing

Output
<pre>
1 => Sayed
2 => Eman
3 => Mahmoud
4 => Osama
5 => Sameh
</pre>
Note

After using "splice()", "i--" is needed so the next element that shifts into the current index is not skipped.
