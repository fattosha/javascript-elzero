<summary><b>Task Description</b></summary>A JavaScript task focused on Boolean values, comparison operators, and logical negation.

It demonstrates how numbers are evaluated as Boolean values and how comparison results can be inverted using the "!" operator.

</details><details>
<summary><b>Concepts Covered</b></summary>">" "<" — comparison operators

"==" — loose equality

"!==" — strict inequality

"!" — logical NOT

"!!" — converts a value into its Boolean equivalent

"Boolean()" — explicit Boolean conversion

</details><details>
<summary><b>Code</b></summary>let num1 = 10;
let num2 = 20;

console.log(num2 > num1); // true
console.log(num1 < num2); // true
console.log(!!num1); // true
console.log(!(num1 == num2)); // true
console.log(num1 !== num2); // true
console.log(Boolean(num2)); // true
