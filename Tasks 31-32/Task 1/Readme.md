<summary><b>What Does This Task Cover?</b></summary>This task focuses on JavaScript comparison operators and how JavaScript handles different data types during comparisons.

It also demonstrates numeric conversion using unary "+" and "-".

</details>Operators

<details>
<summary><b>Comparison Operators</b></summary>"==" — compares values with type coercion.

"<" ">" "<=" — compare numeric values.

</details><details>
<summary><b>Unary Operators</b></summary>"+" converts a value to a number when possible.

"-" converts a value to a number and changes its sign.

</details><details>
<summary><b>Type Coercion</b></summary>JavaScript can automatically convert strings and Boolean values into numbers during numeric comparisons.

Examples from the task include:

""100" → 100"

""-40" → -40"

"false → 0"

</details>Code

console.log(100 == "100"); // true
console.log(100 < 1000); // true
console.log(110 > 100 > 10 < 20); // true
console.log(-10 == "-10"); // true
console.log(-50 < +"-40"); // true
console.log(-10 <= -"-40"); // true
console.log(-"10" == 10); // true
console.log(+20 > false); // true
