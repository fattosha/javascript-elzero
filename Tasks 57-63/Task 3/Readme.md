Task

Create an "ageInTime()" function that converts a person's age from years into different units of time.

The function should accept ages between 10 and 100.

If the age is outside the allowed range, display:

Age Out Of Range

Concepts

- Functions
- Parameters
- "if / else"
- Arithmetic Operators
- Template Literals
- Unit Conversion

Conversions

Years
Months
Weeks
Days
Hours
Minutes
Seconds

Expected Output

Age Out Of Range

Age in Years Is 38
Age in Months Is 456
Age in Weeks Is 1824
Age in Days Is 12768
Age in Hours Is 306432
Age in Minutes Is 18385920
Age in Seconds Is 1103155200
