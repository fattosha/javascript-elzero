Tasks

Task 01 — Say Hello

Created a function that displays a personalized greeting based on:

- Person's name
- Gender
- Optional gender parameter

The function uses "Mr" for males, "Miss" for females, and displays only the name when no gender is provided.

Task 02 — Calculate

Created a function that performs different mathematical operations depending on the provided operation:

- "add"
- "subtract"
- "multiply"

If no operation is provided, addition is used by default.

The function also checks whether the second number exists.

Task 03 — Age In Time

Created a function that converts an age from years into different units of time:

- Months
- Weeks
- Days
- Hours
- Minutes
- Seconds

The function also validates that the age is greater than "10" and less than "100".

Task 04 — Check Status

Created a function that accepts three arguments in random order:

- "String" → Name
- "Number" → Age
- "Boolean" → Availability

The function identifies each value according to its data type and generates a suitable message based on the availability status.

Task 05 — Create Select Box

Created a function that dynamically generates an HTML "<select>" element containing years from a given starting year to an ending year.

<select>
  <option value="2000">2000</option>
  <option value="2001">2001</option>
  <option value="2002">2002</option>
  <!-- ... -->
  <option value="2021">2021</option>
</select>

Task 06 — Multiply

Created a function using Rest Parameters to multiply an unknown number of arguments.

The function:

- Ignores string arguments.
- Converts floating-point numbers to integers.
- Multiplies all valid numbers together.
