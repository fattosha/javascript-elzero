Task

Create a function "checkStatus" that accepts three arguments in any order.

The function should identify each argument according to its data type:

- "String" → Name
- "Number" → Age
- "Boolean" → Hiring Status

Then print the correct message.

---

Examples

checkStatus("Osama", 38, true);
// Hello Osama, Your Age Is 38, You Are Available For Hire

checkStatus(38, "Osama", true);
// Hello Osama, Your Age Is 38, You Are Available For Hire

checkStatus(true, 38, "Osama");
// Hello Osama, Your Age Is 38, You Are Available For Hire

checkStatus(false, "Osama", 38);
// Hello Osama, Your Age Is 38, You Are Not Available For Hire
