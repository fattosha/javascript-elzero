</p>Task — Remove First & Last Elements

This task demonstrates how to remove the first and last elements from an array using:

- "pop()"
- "shift()"

let friends = ["Ahmed", "Eman", "Osama", "Gamal"];

friends.pop();
friends.shift();

console.log(friends); // ["Eman", "Osama"]

Output

["Eman", "Osama"]
