Extract ""zero"" from ""Elzero"" and convert it to uppercase.

Solution

let website = "Go";
let words = [`${website}ogle`, "Facebook", ["Elzero", "Web", "School"]];

console.log(words[2][0].slice(2).toUpperCase()); // ZERO

Concepts Used

- Template Literals
- Array Indexing
- "slice()"
- "toUpperCase()"
- Method Chaining

Output

ZERO
