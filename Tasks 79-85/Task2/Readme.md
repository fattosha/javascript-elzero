Create objects in JavaScript using four different methods.

Each object contains a "property" with a different value, then the property is accessed and printed to the console.

Methods Used

Method One

Using the "Object" constructor:

let objMethodOne = new Object({ property: "Method One" });

Method Two

Using an Object Literal:

let objMethodTwo = {
  property: "Method Two"
};

Method Three

Using "Object.create()":

let objMethodThree = Object.create({
  property: "Method Three"
});

Method Four

Using "Object.assign()":

let objMethodFour = Object.assign(
  {},
  { property: "Method Four" }
);
